# Mindscroll

A personal, TikTok-style learning feed for Android: swipe up for the next idea, swipe right to go deeper.

## Status

Step 1 of the spec's process: style tile and 5 sample cards, so the art direction gets approved before any app screens are built.

- `design/style-tile.html` is a self-contained prototype. Open it in a browser (phone or desktop). It shows the same cards in four art directions (Editorial, Lab notebook, Swiss/brutalist, Terminal/arcade), with real swipe physics, sound and haptics.

Next: lock the direction, then scaffold the Expo + React Native app (Phase 1 in the spec).
